# Movie Watchlist

A movie watchlist built with HTML, CSS, and JavaScript. Add movies, mark them as watched, and keep a saved list of movies you've finished.

## Features

- Add movie titles
- Mark movies watched or unwatched
- Delete movies
- Save watched movies using local storage
- Load watched movies when returning to the page
- Responsive dark theme with Google Fonts

## Built With

- HTML
- CSS
- JavaScript
- Browser Local Storage

## What I Learned

This project helped me practice:

- Creating and removing HTML elements with JavaScript
- Handling button clicks and checkbox changes
- Working with arrays and objects
- Using filter() and forEach()
- Saving and loading data with JSON and local storage
- Keeping displayed elements and stored data in sync

## Run Locally

Download or clone the repository, then open index.html
in your browser. You can also use VS Code's Live Server extension.

## Storage

Only watched movies are saved between visits. Data stays
in the same browser on the same device. Clearing browser
storage removes the saved list.

## Development

Built as a hands-on learning project, with AI assistance
for styling and debugging.
